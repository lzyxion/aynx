# Aynx 보안

[English](security.md) · 한국어

- **볼트는 사용자가 선택해 활성화합니다.** 활성화하지 않으면 비밀번호는 한 번 사용한 뒤 폐기하고 다음 접속 시 다시 입력받습니다. 볼트 값은 세션 서버 프로세스 안에서만
  보관하며 GUI, 설정 파일, 로그, MCP에는 전달하지 않습니다. 개인키 파일 자체는 저장하지 않습니다. 마스터 암호를 설정하지 않으면
  이 PC의 사용자 계정으로 로그인한 누구나 볼트를 열 수 있으며, 앱 화면에 이 사실을 안내합니다.
- **알려진 예외:** 외부 stdio MCP 서버의 환경 변수 값은 볼트가 열려 있는 동안 해당 서버에 평문으로 전달합니다. 해당 타일의
  에이전트를 포함해 같은 계정으로 실행하는 프로세스에서 볼 수 있는 값으로 간주합니다.
- **MCP 서버는 읽기, 작업안 작성, 오케스트레이션 조율만 지원하며, 명령 실행·키 전송·승인 도구는 제공하지 않습니다.** CLI 전역 설정에는 등록하지 않습니다. 토큰은 Aynx가
  실행하는 로컬 AI 타일과 셸 통합 로컬 셸 타일에만 제공하며, 원격 타일에는 신호 전용 토큰만 제공합니다.
- **실행은 맡긴 범위 안에서만:** 사용자가 앱에서 승인하거나 범위를 명시한 자동 승인 정책에 따라 실행합니다. AI는 자신의 작업안을 스스로
  승인할 수 없습니다. 오케스트레이션 아티스트는 사용자가 앨범에서 정한 권한 등급으로 실행하며, main 병합은 사용자의 [병합] 또는 사용자가 앨범마다 켠 자동 병합(검증 명령과 위험 확인 필요)으로만 이뤄집니다. AI나 MCP에는 그 길이 없고, 앱은 push하지 않습니다.
- **검증 명령과 아티스트는 샌드박스 없이 사용자 권한으로 실행합니다.** OS 수준의 격리는 아직 지원하지 않습니다.
- **원격 웹 접속**은 `127.0.0.1`에서만 접속을 받고 메인 PC의 `tailscale serve`(직접 설정하거나 설정의 [연결] — Funnel은 켜지 않습니다)로만 접근할 수 있습니다. 기기는 메인 PC에서 페어링해야 합니다.
  볼트 값, MCP 토큰, 웹훅 URL은 원격 창에 전달하지 않습니다.
- 포트 포워딩은 `127.0.0.1`에서만 접속을 받습니다. 에이전트 포워딩은 기본적으로 꺼져 있으며 호스트별로 활성화합니다.
- 세션 로깅은 기본적으로 꺼져 있으며 세션별로 활성화합니다.
