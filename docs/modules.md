# 백엔드 모듈 지도 (`src-tauri/src/`)

grep 없이 **고칠 파일을 찾고**, 고치기 전에 **그 파일의 불변식**을 보는 한 장이다. 불변식과 "왜" 는 각 파일의
`//!` 머리말에 있고(여기는 옮겨 적지 않는다), 사건 기록은 [log/](log/) 에 있다.
프런트(`src/lib/`) 지도와 배럴 규칙은 [modules-frontend.md](modules-frontend.md).

- 모듈 70개 · 간선은 `node scripts/dev/rust-module-scc.mjs --edges` 로 다시 뽑는다(이 표는 2026-10-01 기준).
- **테스트** 칸: `tests.rs` = `src/<모듈>/tests.rs` · `인라인` = 파일 안 `mod tests` · `—` = 없음.
  pty 는 셸 조립 테스트가 `src/pty/shell_tests.rs` 에 따로 있다.
- 층은 **의도한 모양**이다. 지금 어긋난 자리는 행 끝에 "현재 위층을 부름: …" 으로 적었다 — 깨끗한 척하지 않는다.
  가장 큰 강결합 덩어리(SCC)는 36개 모듈이고 `ssh` 가 그 가운데에 있다.
- 모듈 하나가 폴더로 나뉜 곳: `ssh.rs` · `mcp.rs` · `sftp_browser.rs` · `operations.rs`(부모 — 머리말·`mod`·재수출) + `src/ssh/*.rs` · `src/mcp/*.rs` · `src/sftp_browser/*.rs` · `src/operations/*.rs`(역할별 자식). 스크립트는 자식을 부모 하나로 센다.

층: **바닥**(아무것도 모르는 부품·저장 파일) → **세션 층**(로컬·원격 세션의 수명) → **기능 층**(세션 위의 기능)
→ **명령·조립 층**(여러 저장소를 함께 만지는 명령 · 앱 조립). 아래 층은 위 층을 부르지 않는 것이 목표다.

## 세션 서버 층 (`server.rs` + `server/` — 설계 internal/session-server-design-2026-10-08.md ③)

분리 프로세스 `aynx session-server` 와 그것을 찾거나 띄워 붙는 GUI 쪽 클라이언트. **③-2**: 로컬 PTY 세션은 서버에 산다 —
GUI 의 로컬 명령은 같은 이름의 프록시(`server/proxy.rs`), 출력은 이진 출력 프레임 + ACK 크레딧, GUI 연결이 끊기면(종료·kill) 임대만 풀린다.
**③-3a**: 신호 평면(신호 토큰 표 `agent_signal` · 에이전트 상태 표 `agent_state` · `/agent-signal` 수신)도 서버에 산다 — 서버의
127.0.0.1 임시 포트(`hello`·`status` 의 `signal_port`), 받은 신호는 서버 이벤트 `agent-signal` → GUI 가 같은 이름의 Tauri 이벤트로 중계.
로컬 타일의 신호 토큰은 서버의 `open` 이 뽑아 자식 환경에 넣고(파이프를 타지 않음) 원격 타일만 `signal_issue` 로 GUI 에 간다.
**③-3b1**: 볼트 평면(금고 · 외부 MCP 실행 브로커 · HTTP 헤더 프록시)도 서버에 산다(`server/vault_ops.rs`) — 볼트 값은 서버 프로세스 밖으로
나가지 않고(과도기 op 하나 — b2 에서 삭제), 클라이언트 0 이면 서버가 창 0개 잠금(HTTP 티켓 정지), 가림막 잠금은 티켓 폐기.
**③-3c**: AI 평면(MCP `/mcp`·`mcp.json`·거울·라우팅·작업안·결과·실행기·만료·감사)도 서버에 산다(`server/ai.rs`) — `/mcp` 는 신호 평면과 **한 리스너**(경로별 문지기·토큰 종류·동시 상한 분리), 승인 등급 프레임은 GUI 의 `approve_operation` 하나가 만든다(`client::request_approve`)·서버가 판정을 다시 한다. 서버가 못 뜨면 로컬 타일은 열리지 않는다("세션 서버에 닿지 못했습니다").

**③-4**: 창 0개 정책 — **사전 정책 자동 승인의 시계는 서버**(`operations/auto.rs` — 서버 안 함수 호출 `approve_in(method: auto)` 하나, 파이프 승인 프레임 아님 · 검토 중 카드는 GUI 가 `ops_reviewing` 으로 알림), GUI 가 하나도 없을 때 끝난 실행은 서버의 **미전달 큐**(`ops_unseen_take`)와 메신저(`operations/notify.rs`), 창이 0개인 트레이 GUI 는 GUI Rust 가 OS 알림·메신저(`tray.rs`). **떨어진 세션 목록**(`sessions_detached`·`close_detached` — 복원이 데려가지 않은 세션은 `restore_done` 이 **닫지 않고** 표시만, 옛 `release_unclaimed` 삭제) · 로컬 "AI 읽기 허용" 세션 메타(`session_ai_read` · `probe.aiRead`) · 찾기 파일의 `sessions`(NSIS 설치기 훅 `src-tauri/nsis/hooks.nsh` 가 읽어 경고) · 판 7.
GUI 는 **한 개**(single-instance 플러그인 — 둘째 실행은 첫 창을 앞으로, identifier 로 개발/릴리스 구분).
