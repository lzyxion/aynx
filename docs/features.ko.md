# AYNX 전체 기능

[English](features.md) · 한국어

**작업 공간과 타일**
- 이진 분할 트리 방식의 타일 배치(나선·포커스 배치), 끌어다 놓기로 위치 변경, 탭에서 선택한 타일에 같은 입력 전송.
- 주 창과 보조 창에서 여러 워크스페이스와 탭을 사용합니다. 탭과 타일을 분리해 새 창으로 열 수 있습니다.
- 호스트·프로젝트·DB, 실행 버튼, 알림을 모은 런처 독, 하단 독의 즐겨찾기, 명령 팔레트(`Ctrl+Shift+P`).
- 모든 탭과 타일의 지도를 보여 주는 세션 판(`Ctrl+Shift+M`).
- 시작 화면 위젯(시계, 셸, 호스트, 프로젝트)과 편집 모드.
- 로컬 자원 모니터: 상태바의 CPU·메모리 원형 표시, 타일별 자원 칩, 차트가 있는 자원 화면.

**세션**
- 로컬 셸(PowerShell, cmd, Git Bash, WSL)과 SSH. 기본 셸 하나를 지정하고, 다른 셸은 필요할 때 셸 메뉴에서 실행합니다.
- SSH: 연결 공유, 경유 호스트(한 단계), 포트 포워딩(`-L` · `-R` · `-D`), 호스트별 에이전트 포워딩, tmux 세션 연결,
  접속 후 명령, 시작 시 자동 재접속, 접속 이력.
- `~/.ssh/config`를 직접 수정하는 호스트 입력 폼, 키 생성, 공개키 설치, 저장된 호스트 키 삭제.

**세션 서버와 트레이**
- 세션은 별도의 `aynx session-server` 프로세스에서 실행됩니다. GUI를 종료하거나 강제로 종료해도, 웹뷰가 비정상 종료되어도 창과의 연결만 끊깁니다.
  셸은 계속 실행되며, 다음에 앱을 실행하면 다시 연결합니다.
- 마지막 창을 닫으면 트레이에 남습니다(설정에서 해제 가능). 트레이 메뉴에서 창 다시 열기, GUI만 종료, 모든 세션 종료를 선택합니다.
- 화면 배치를 복원할 때 연결되지 않은 세션은 **떨어진 세션**으로 유지합니다. 새 탭에 연결하거나 종료할 수 있습니다.
- 세션, 클라이언트, 작업안이 모두 없는 상태로 10분이 지나면 서버가 자동으로 종료됩니다.

**터미널**
- 현재 타일에서 찾기(`Ctrl+F`), 모든 터미널에서 찾기(`Ctrl+Shift+F`), 명령 블록 검색.
- 셸 통합(OSC 133 명령 블록, OSC 7 현재 폴더) — PowerShell, Git Bash, WSL, 원격 bash.
- 명령 출력을 서식에 맞춰 표시: JSON 트리·표, CSV, 열을 정렬한 표, 마크다운.
- WebGL 가속, 합자, 인라인 이미지(sixel·iTerm2), OSC 52 클립보드, OSC 8 링크, OSC 9·777 알림.
- 스니펫, 정규식 트리거(하이라이트·링크·툴팁), 오래 실행되는 명령의 완료 알림, 세션별로 켜는 세션 로깅.

**파일 · 문서 · DB**
- 파일 타일(SFTP·로컬): 장소 패널, 다양한 보기, 미리 보기, 업로드, 끌어다 놓기, 이 PC의 편집기로 원격 파일 편집.
  로컬 파일 타일은 파일이 바뀌면 자동으로 새로 고침합니다. 원격 파일 타일은 필요할 때 직접 새로 고침합니다.
- 문서 타일: 로컬·원격 파일의 마크다운 미리 보기(mermaid, 목차, GFM)와 앱 내 편집(`Ctrl+S` 저장, 충돌 감지).
- 쿼리 타일(PostgreSQL, MySQL / MariaDB, SQLite): 직접 연결하거나 호스트의 SSH 연결을 거쳐 접속합니다. 기본은 읽기 전용이며, 쓰기는
  타일별로 활성화하고 트랜잭션 안에서 실행합니다. 결과는 표나 차트(선·막대·산점도)로 표시합니다. DB 비밀번호는 볼트에만 저장합니다.

**프로젝트와 git**
- 로컬·원격 프로젝트와 git 워크트리(브랜치당 워크트리 하나), 변경 배지, 브랜치·커밋 그래프 타일.
- diff 타일: 줄별로 코멘트를 달아 AI 타일에 전달합니다.
- 프로젝트 시작 화면에서 이전 에이전트 대화를 재개하거나 새 대화로 이어 갈 수 있습니다. 대화 기록도 확인할 수 있습니다.

**AI 에이전트**
- Claude Code·Codex 타일과 훅 신호에 따라 바뀌는 상태 글리프(로컬·원격), 터미널 옆 대화 화면.
- 로컬 AI 타일 대화 화면의 권한·질문 카드.
- 세션 연결 칩, 그림 첨부, 출처 칩을 지원하는 사이드 채팅 독(데스크톱과 원격 창).
- 파일 타일에서 AI 타일로 파일 첨부, 에이전트별 추가 인자, 에이전트 실행 전에 수행하는 프로젝트별 설정 스크립트.
- 로컬 PowerShell·Git Bash 타일(셸 통합 켬)에서 입력한 Claude Code·Codex도 AI 타일과 같은 연동을 받습니다.
- 에이전트 지침을 한곳에서 관리하고, 각 에이전트의 지침 파일에 관리 블록으로 기록합니다.
- 앱 전체 또는 프로젝트별로 설정하는 외부 MCP 서버(stdio·HTTP). 환경 변수와 헤더의 비밀 값은 볼트에 저장할 수 있습니다.
- Claude Code·Codex 사용량 화면 — 이 PC 또는 연결된 호스트 기준.

**작업안과 승인**
- AI 권한은 호스트별로 Off(끔), Read(읽기), Ask(승인 후 실행), Auto(허용 목록 자동 실행), YOLO(무엇이든 자동 실행) 중 하나를 설정합니다. 로컬 타일은 타일별로 Off · Read 만 고를 수 있으며,
  명령 실행 대상으로는 지정할 수 없습니다.
- AI가 작업안(명령 + 대상)을 제출하면 사용자가 앱에서 승인합니다. 승인한 작업안은 순차 canary 방식으로 실행하며 감사 로그를 남깁니다.
- 승인 카드에는 AI가 작성한 요약과 선언한 효과, 앱이 명령 원문을 분석한 결과를 나란히 표시합니다. AI가 선언한 효과가 앱의 분석보다 약하면 카드를
  빨간색으로 표시하고 두 번 클릭해야 승인하도록 합니다.
- 자동 승인 정책: 허용 패턴, 인자까지 확인하는 명령 묶음(파이프는 별도로 허용).
- DB 연결별 AI 권한(Off·Schema·Read·Ask·YOLO). AI는 별도로 연 읽기 전용 연결로만 데이터를 읽으며, 쓰기 작업은
  사용자가 승인할 초안으로만 제안합니다.
- 앱·OS 알림과 선택적으로 사용하는 Discord·Slack 웹훅 알림('승인 대기' 포함).

**오케스트레이션**
- 오케스트레이션 탭은 **앨범**(Run)과 그 안의 **트랙**(Task)을 모은 라이브러리이며, 앨범은 저장소마다 **스튜디오**로 묶입니다. **아티스트**는 권한이 없는 프로필(이름, CLI, 모델, 지침)입니다.
- 라이브러리에는 스튜디오마다 카드, **최근** 앨범(진행 중인 앨범 먼저), 앨범 목록이 있으며, 앨범 목록은 정사각 표지 카드나 줄로 볼 수 있습니다.
- **새 앨범**에서 저장소, 아티스트와 권한 등급, 수락 규칙, 검증 명령, 한도를 정하고 첫 말을 보내 시작합니다.
  AI 타일의 대화를 갈라 새 앨범으로 이어 갈 수도 있습니다.
- **프로듀서**는 앨범을 조율하는 읽기 전용 채팅입니다. 아티스트는 각자의 git worktree에서 헤드리스로 실행하며, 검토 아티스트는 보고된 커밋을 읽고 판정만 수행합니다.
- 수락된 트랙은 통합 ref에 하나씩 squash합니다. 수락 전 검증 명령은 사용자가 확인한 뒤 실행하거나, 사용자가 활성화한 자동 실행
  범위 안에서만 실행합니다.
- 끝난 앨범은 **정리** 창에서 읽기 전용 브랜치 그래프를 보며 지울 작업 폴더를 골라 지웁니다.
  다 쓴 앨범은 **보관함**으로 옮기고, 보관함에서 끝난 기록으로 복원하거나 영구 삭제할 수 있습니다.
- 앨범을 시작하거나 권한을 넓히는 일은 사람만 할 수 있습니다. AI나 MCP에는 그 길이 없습니다. **main 병합은 사용자의 [병합] 단추 또는 사용자가 앨범마다 켠 자동 병합으로만 이뤄집니다. AI나 MCP에는 그 길이 없고, push는 하지 않습니다.**

**원격 웹 클라이언트**
- Tailscale tailnet 내 다른 PC나 휴대전화의 브라우저에서 앱에 접속합니다. 앱은 `127.0.0.1`에서만 접속을 받고,
  tailnet에는 사용자가 직접 설정하거나 메인 PC 설정의 [연결]로 건 `tailscale serve`로만 노출합니다. 해당 포트가 Funnel로 공개되어 있으면 접속을 허용하지 않습니다.
- 새 기기를 연결할 때는 메인 PC에서 사용자가 6자리 코드가 일치하는지 확인해 페어링합니다.
- 대화 화면을 갖춘 휴대전화용 화면과 원격 작업안 승인(마스터 암호를 설정했다면 승인 시 다시 확인).
- 원격 창이 열려 있는 동안 메인 PC에는 OS 알림과 '원격 접속 중' 표시가 항상 나타납니다.

**볼트와 보안**
- 선택적으로 활성화하는 볼트(암호화한 파일 하나)에 비밀번호, 키 암호구, DB 비밀번호, MCP 비밀 값을 저장합니다. 마스터 암호는 선택 사항입니다.
- 가림막과 볼트 잠금은 연동됩니다. 가림막을 켜거나 열린 창이 하나도 없으면 볼트를 잠급니다. 일정 시간 입력이 없을 때 자동으로 잠그는 기능은 선택 사항입니다.
- 설정 › 보안에 들어갈 때마다 잠금을 해제하거나 마스터 암호를 확인합니다.

**모양**
- 색 테마나 월페이퍼에서 추출한 색을 바탕으로 구성하는 Material 3 역할별 톤 색상, 밝기 모드(라이트·다크·시스템).
- 앱 크롬의 재질은 글래스와 평면 중에서 선택합니다. 투명도 슬라이더로 패널과 타일에 월페이퍼가 비치는 정도를 조절합니다.
- 월페이퍼 효과(어둡게·블러·색 입히기), 상태바 모양(창에 붙임·패널·감싸기), 탭 모양, 타일 머리줄에 표시할 칩 선택.
- 테마 프로필과 빠른 전환(`Ctrl+Shift+U`).
- 앱 아이콘은 내장 캐릭터(GPT 기본, Claude, Gemini, Grok)나 직접 추가한 그림에서 선택합니다. 직접 추가한 그림도 같은 둥근 모양으로 자릅니다.
- 한국어·영어 UI.
